Send commands to the net callsign once you have checked in.

CI / CO
Check in / check out.
STG / STY / STR
Set your status color to green, yellow, or red. Participant lists show (G), (Y), or (R).
T name
Set tactical callsign.
F frequency
Set voice frequency monitoring.
X watts
Set transmit power.
E (BATTERY, COMMERCIAL, GENERATOR, NONE, SOLAR)
Set primary electrical power type.
B (BATTERY, COMMERCIAL, GENERATOR, NONE, SOLAR)
Set backup electrical power type.
Y (APPLIANCE, BASE, HANDHELD, INTERNET, MOBILE, OTHER)
Set radio style

These commands can be combined into a single message.

S text
Set status.
M text
Send message to all active participants.
MC text
Send message to Net Central console only.

L
List participants.
P callsign
Ping a participant.
I
Get information about net.
H
Help and supported commands.
R count
Replay last (count) number of messages.
Q text
Ask a question of all net participants.
QL
List your unanswered questions.
QR number
Get answers to question by question number.
A number text
Answer a question by number.
INV callsign
Invite station to a net.
NCI
Toggle net participation notification.

Send these commands to the enabled Net Manager callsign.

L
List nets.
C callsign
Create an open net.
CP callsign
Create a closed-admission net.
S callsign
Secure a net created by that exact station.
H
Get help.

Send commands to the priority object (nets, EOC, shelter) callsign.

?INFO
Net - Net information and participants.
Priority Object - name, comment and supported directed query commands.
?CMD
List of valid directed query commands.
?APRSO
Object information.
?APRSP
Object position.
?NCOT
Object type.
?NCNTI
Net - Net information.
?NCNTP
Net - Net participants.
?NCPI
Priority Object - name, comment.
?NCPES
Priority Object / EOC - EOC status.
?NCPEM
Priority Object / EOC - EOC mobilization report.
?NCPSS
Priority Object / Shelter - shelter status.
?NCPSC
Priority Object / Shelter - shelter census.
?NCPSF
Priority Object / Shelter - shelter food reports.
?NCPSM
Priority Object / Shelter - shelter materiel reports.
?NCPSW
Priority Object / Shelter - shelter worker census reports.

Send commands to the general resource object callsign.

R
Request resource values.
key=value
Set a resource value when authorized.
?INFO
Name, comment and supported directed query commands.
?CMD
List of valid directed query commands.
?APRSO

?APRSP
Object position.
?APRSS
Object status.
?NCGRI
