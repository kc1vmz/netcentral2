Description of task

Create a Net Central priority object representing a shelter or emergency operations center (EOC). The object has an APRS identity, symbol, and location, and can beacon through selected communication instances. Its details page stores operational reports and their history.

Shelter objects track status, population, workers, food, and materiel. EOC objects track contact and mobilization information. These are managed Net Central objects, distinct from generic APRS objects heard from other stations.

Prerequisites

  • Sign in to Net Central. Use the creating account or an authorized administrator for subsequent management.
  • Choose an available object callsign, up to nine characters, and know the facility's latitude and longitude. Avoid conflicts with existing managed objects or running nets.
  • Decide whether this is a Shelter or EOC and prepare a concise identifying comment.
  • Have an administrator configure and verify the communication instances that will carry the object's beacons and messages.
  • Collect the initial operational information you intend to publish. Review which stations should be allowed to update object information through the Object security settings.

Steps to accomplish

  1. Open Explorer and select Create object.

  2. Enter the Callsign. This identifies the object and is the destination for its directed APRS queries.

  3. Choose Type:

    • Net Central Shelter Object for shelter status and operational reporting.
    • Net Central EOC Object for emergency operations center contact and mobilization reporting.

    Do not leave the default General Resource type selected when creating a Shelter or EOC.

  4. Set Object location. Choose Manual entry and enter decimal-degree latitude and longitude, or choose Use map and click the facility's location. Drag the marker to adjust it. Latitude must be between -90 and 90 and longitude between -180 and 180; south and west use negative values.

  5. Enter a Comment identifying the facility or its purpose, up to 80 characters, and choose an appropriate APRS symbol.

  6. Leave Active (send periodic beacons) checked if the object should beacon. Choose Communications: the default uses all eligible instances, including future ones. To limit the object, choose Selected instances and check the intended connections. An empty selection transmits nowhere.

  7. Select Create, review the callsign, location, and settings in the creation workflow, and confirm. To abandon creation instead, select Cancel and confirm discarding changes.

  8. On the object's details page, enter its initial operational information using the Update buttons:

    Object typeInformation groups
    EOCContact information and Mobilization information.
    ShelterStatus information, Population census, Worker census, Food availability and needs, and Materiel availability and needs.

    Open the appropriate group's dialog, fill in the fields, select Update, and confirm the change. For groups with multiple categories, use the Update button for the intended category. Repeat for the remaining information you have available.

  9. Review the latest values and history after each update. Shelter status distinguishes Stand-by or Active from Open or Closed; these operational values are separate from the object's beaconing checkbox.

Verifying success

  1. Confirm that the object details show the intended callsign, location, status, and symbol description.
  2. Return to Explorer and select the appropriate resource type. Select the object and use View details to reopen it. Check its location on the map.
  3. Confirm each submitted report appears in the appropriate latest-information group and its history. An object can exist before any operational reports have been entered.
  4. Check the selected instances on Communications, or ask an administrator to check them, and verify reception of the beacon using another APRS client or receiver. A saved object does not by itself prove remote reception.
  5. From another APRS station, address ?INFO to the object's callsign to request its identifying information and supported queries. Use ?CMD for the supported command list, ?NCPI for its identifying name/comment information, or ?APRSP for its position. Verify a reply through an eligible connection.

Additional considerations

  • Object security: Administrators manage radio update permissions under Settings → Object security. Review those rules before relying on remote updates. Browser management permissions and radio update rules are separate controls.
  • Beacon timing: Settings → Announcements controls Beacon seconds. An eligible connection must be available and allow transmission for outgoing beacons.
  • Operational status: Shelter Active/Stand-by and Open/Closed describe the shelter. They do not replace the object's Active setting, which controls periodic beaconing.
  • History: Update the reporting groups to record changing conditions. Use the displayed histories to review earlier reports rather than assuming a current value describes the entire event.
  • Editing: Use Edit to change the object's configuration. Its callsign is read-only when editing, so choose that identity carefully at creation.
  • Withdrawal: Withdraw object asks for confirmation, sends a withdrawal, and deletes the managed object so its callsign can be reused. It does not wait for remote confirmation. Preserve any operational records you need before withdrawing; this is not the same archival workflow as securing a net.
  • Multiple connections: All eligible instances includes instances added later. Use Selected instances when the facility should be advertised only over specific connections.
  • Kenwood: Kenwood Serial uses its configured MYCALL as the RF source. The object has its own identity within the APRS object information; verify how it appears on the receiving client.
  • Missing replies: Check the exact object callsign, selected instances, connection state, transmission permission, and applicable security rules. Use the supported command list rather than assuming all object types accept the same report commands.
