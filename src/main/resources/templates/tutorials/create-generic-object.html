Description of task

Create a Generic APRS Object to advertise a named location with an APRS symbol and comment. Net Central manages the object and can send periodic beacons through the communication instances you select.

A Generic APRS Object provides a simple location marker. It does not have the operational reporting groups of Shelter or EOC objects, or the key/value fields of a Net Central General Resource.

Prerequisites

  • Sign in to Net Central.
  • Choose an available object callsign of up to nine characters. Avoid conflicts with existing managed objects or running nets.
  • Know the location to advertise, choose an appropriate APRS symbol, and prepare a short identifying comment.
  • Have an administrator configure the radio or Internet communication instances you intend to use. For beacon transmission, the selected connections must be available and allow transmission.

Steps to accomplish

  1. Open Explorer and select Create object.

  2. Enter the object's Callsign. This is its APRS object identity, not necessarily the source callsign of the station transmitting its beacon.

  3. Set Type to Generic APRS Object. The form initially selects Net Central General Resource, so change this explicitly for a generic object.

  4. Set Object location using one of the two methods:

    • Manual entry: Enter latitude and longitude in decimal degrees. Latitude must be between -90 and 90; longitude between -180 and 180. Use negative numbers for south and west.
    • Use map: Click the intended location, then drag the marker if necessary. Review the displayed coordinates before continuing.

    Both coordinates are required for creation.

  5. Enter a Comment of up to 80 characters describing the location or its purpose. Choose the desired APRS symbol using the symbol picker.

  6. Leave Active (send periodic beacons) checked to advertise the object periodically.

  7. Choose Communications. Keep All eligible instances, including future ones to use all eligible connections, or choose Selected instances and check the intended connections. An empty selected set transmits nowhere.

  8. Review the callsign, type, coordinates, comment, symbol, and communication selection. Select Create and confirm the creation dialog. To abandon the form instead, select Cancel and confirm discarding the changes.

  9. Review the resulting Object Details pane. It shows the callsign, location, status, symbol and description, and comment. A Generic APRS Object does not display resource-value or priority-report panes.

Verifying success

  1. Confirm that Object Details shows the intended callsign and coordinates, Active status, and the expected symbol and comment.
  2. Return to Explorer, choose an appropriate object resource filter, and locate the object. Select it and use View details to reopen its details page.
  3. Verify that the map marker appears at the intended location. If it does not, review the coordinates and current Explorer filter.
  4. Check the selected instances on Communications, or ask an administrator to check them. Confirm outgoing traffic and verify the object's appearance on another APRS client or receiver.
  5. If a remote client does not show the object, check its filters, the selected communication instances, transmission permission, and beacon interval. Saving the object locally does not prove remote reception.

Additional considerations

  • Choosing the right type: Use Net Central General Resource when you need named key/value information. Use Shelter or EOC for their operational reporting groups. Choose Generic APRS Object for a simple marker with a comment and symbol.
  • Editing: The creating account or an authorized administrator can use Edit on the details page to change the configuration. Select Update and confirm to save changes. The callsign is read-only when editing.
  • Beacon interval: Settings → Announcements controls Beacon seconds. Active enables periodic beaconing; it does not guarantee an available route or successful delivery.
  • Communication scope: All eligible instances includes connections created later. Selected instances keeps the object limited to the connections you choose.
  • Ownership: Seeing an object heard from another station in Explorer does not make it locally managed. Management controls apply to objects managed by Net Central and require the appropriate permissions.
  • Withdrawal: For an active object you manage, select Withdraw object and confirm to send a withdrawal and delete the object and its associated data. The callsign can then be reused. This does not wait for remote confirmation, so other clients may retain the old marker until they receive the withdrawal or expire their cached data.
  • No net archive: Withdrawing an object is not the same as securing a net. Preserve any information you need before deletion.
  • Kenwood: Kenwood Serial transmits using its configured MYCALL as the RF source. The object's identity is carried within the APRS object packet; verify the object name and location on the receiving client.
